# BattleGround Fitness Club website

A responsive, static one-page website built from the supplied club listing, promotional images, and video. It uses no build step or third-party JavaScript dependencies.

## Preview locally

Open `index.html` in a browser, or serve this folder with any static file server. Keep the `assets` folder beside `index.html`; the gallery video and images load from there.

## Publish publicly

1. Confirm the gym owner approves the copy, photos/video, contact details, address, current services and membership wording. The supplied offer poster mentions ₹3,000 prebooking and ₹13,000 yearly with an October 15 deadline, which has passed; this site therefore asks visitors to enquire about current terms.
2. Put the project in a GitHub repository and import it into Netlify or Cloudflare Pages. Set the publish directory to the repository root; no build command is needed. Alternatively upload the files to any static host.
3. Test the published page on a phone and desktop, including WhatsApp, phone, Instagram, directions, map, navigation, and video. The map embed needs an internet connection.
4. Use the final public URL in the owner's pitch. Connect a domain only after the owner agrees and controls the domain account.

## Details to confirm with the owners

- Exact street/building entrance (the listing says Subhash Nagar; posters show Ratan Heritage and Sai Krupa Building).
- Current opening hours and whether the club is open to visitors.
- Current membership prices, inclusions, eligibility, and offer expiry.
- Current availability of trainers, sports nutrition guidance, steam room and lockers.
- Permission to publish the supplied brand imagery and video.

## Owner pitch

Show the site on a phone first. Point out that a nearby searcher can understand the training options, see the club visuals, get directions, and ask about membership in one flow. Then ask the owners to confirm hours, current rates, and preferred photos so the preview can become the official site. Offer to connect their domain and update the page once those details are approved.
